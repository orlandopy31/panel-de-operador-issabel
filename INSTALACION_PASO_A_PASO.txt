PANEL DE OPERADOR ISSABEL — GUÍA PASO A PASO
=============================================
Compatibilidad prevista: Issabel 5. Se recomienda probar primero fuera de producción.
IMPORTANTE: NO ejecutar install.sh sobre un panel personalizado sin revisar el respaldo.
Identificadores internos conservados: panel_lite e issabel-panel-lite.service.

A) INSTALACIÓN NUEVA
-------------------
1. Hacer snapshot o backup completo del servidor Issabel.
2. Subir panel_de_operador_issabel_github_con_guia.zip a /root/ con WinSCP o SCP.
3. Conectarse por SSH como root.
4. Preparar herramientas:
   dnf install -y unzip sqlite
5. Descomprimir:
   mkdir -p /root/panel-de-operador-issabel
   unzip /root/panel_de_operador_issabel_github_con_guia.zip -d /root/panel-de-operador-issabel
   cd /root/panel-de-operador-issabel
6. Comprobar requisitos:
   test -f /var/www/db/acl.db && test -f /var/www/db/menu.db
   systemctl status asterisk --no-pager
   php -m | grep -i sqlite
   ls -la panel_lite service
7. Revisar config AMI en panel_lite/configs/default.conf.php y service/daemon.php.
   Evitar publicar credenciales en GitHub.
8. Revisar el script y su sintaxis:
   bash -n install.sh
   less install.sh
9. Si se trata de instalación NUEVA y se acepta la sustitución del módulo:
   bash install.sh
   NOTA: el script sustituye por completo /var/www/html/modules/panel_lite,
   creando respaldo del módulo previo en /root/panel_lite_backup_FECHA.
10. Verificar estado:
    systemctl status issabel-panel-lite.service --no-pager
    journalctl -u issabel-panel-lite.service -n 80 --no-pager
    ls -lah /var/lib/issabel-panel-lite/
11. Ingresar a Issabel, abrir PBX > Panel de Operador Issabel y presionar Ctrl+F5.

B) ACTUALIZAR UN PANEL YA INSTALADO
-----------------------------------
1. Respaldar el servidor y guardar cualquier personalización de PHP, JS o CSS.
2. Subir y descomprimir el ZIP como en A.2–A.5.
3. Comparar los archivos del cliente, porque el actualizador los SUSTITUYE:
   diff -u /var/www/html/modules/panel_lite/api.php panel_lite/api.php || true
   diff -u /var/www/html/modules/panel_lite/index.php panel_lite/index.php || true
   diff -u /var/www/html/modules/panel_lite/themes/default/js/panel.js panel_lite/themes/default/js/panel.js || true
   diff -u /var/www/html/modules/panel_lite/themes/default/css/panel.css panel_lite/themes/default/css/panel.css || true
4. Comprobar el script:
   bash -n actualizar_grupo55_redimension.sh
5. Actualizar SOLO si los cambios resultan compatibles:
   bash actualizar_grupo55_redimension.sh
6. Actualizar el navegador con Ctrl+F5, comprobar los grupos y tamaños por usuario.
7. El script deja copia de los cuatro archivos en /root/panel_lite_pre_resize_FECHA.
   No reinicia Asterisk ni cambia datos SIP/PJSIP.

C) SI NO EXISTE EL GRUPO SUPERVISORES
------------------------------------
La aplicación usa exactamente 'Supervisores' (plural), no 'Supervisor'.
1. Entrar a Issabel como admin.
2. En Sistema > Usuarios/Grupos (según menú de la versión), crear 'Supervisores'.
3. Crear o asignar los usuarios a ese grupo.
4. En permisos de grupos, conceder acceso al recurso 'panel_lite'
   (Panel de Operador Issabel). El instalador solo da acceso automáticamente
   si 'Supervisores' ya existe al instalar.
5. Cerrar sesión y volver a entrar con el supervisor.
6. Verificar desde SSH, en modo lectura:
   sqlite3 /var/www/db/acl.db "SELECT id,name FROM acl_group WHERE lower(name) LIKE '%supervis%';"
   sqlite3 /var/www/db/acl.db "SELECT id,name FROM acl_resource WHERE name='panel_lite';"
7. Si no aparece el menú, comprobar además el permiso 'access' para el recurso.
   Ver README.md para consultas SQL de diagnóstico más detalladas.
No dar acceso irrestricto de administrador ni modificar la base ACL a ciegas.

D) PRUEBAS FINALES
-----------------
- Admin: arrastrar una extensión del grupo 1 al 55 y de 55 al 17.
- Supervisor autorizado: repetir la operación.
- Usuario A: redimensionar un grupo y recargar la página.
- Usuario B: darle otro tamaño; verificar que no afecte el usuario A.
- Confirmar que las extensiones siguen funcionando y que el servicio está activo.

E) GITHUB
---------
1. Crear repositorio PRIVADO llamado 'panel-de-operador-issabel'.
2. Descomprimir el ZIP en una carpeta local, abrir terminal en ella:
   git init
   git branch -M main
   git add .
   git commit -m "Panel de Operador Issabel - primera versión"
   git remote add origin https://github.com/USUARIO/panel-de-operador-issabel.git
   git push -u origin main
3. Reemplazar USUARIO por cuenta/organización que sea propietaria.
4. Antes de hacerlo público, auditar secretos, datos de clientes y licencias.

Leé README.md antes de instalar para conocer rutas, reversión y seguridad.
